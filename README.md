# Cuddle Critters — Ada's Game

A playable island creature adventure built from Ada's original drawings and creature ideas.

## Play locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite. The production build is created with:

```bash
npm run build
```

## How to play

- Tap **Explore** to reveal the next undiscovered critter.
- Tap a critter on the island to begin an encounter.
- Swipe the gold-and-silver pod upward, click it, or press **Space** to cuddle-catch.
- Open the **Field Guide** to revisit discoveries and see Ada's source sketches.
- Catch MiCo to unlock its evolution into Mika Chu.

Progress is saved in the browser. All game creatures, capture devices, art, names, and interface elements are original to this project.
